和语言相关的就不推荐了，感觉大部分人都有安装。  
vscode、cursor、trae、windsurf 等编辑器都可以使用。

## 1. 开发

### 1.1. [File Nesting Updater - Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=antfu.file-nesting)

自动同步并更新他维护的文件嵌套配置，让文件资源管理器更整洁。

![Pasted image 20251020141840](https://pictures.kazoottt.top/2025/10/20251020-cd5447894897e788e70684ff1dba8c61.png)

### 1.2. [Turbo Console Log - Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=ChakrounAnas.turbo-console-log)

快速生成有意义（可以看到文件的行数、函数名称、变量名称）的日志，一键删除添加的 log。

![IMG-8BE5636A37F380C6C86B708C0C2BD3AD](https://pictures.kazoottt.top/2025/10/20251020-8be5636a37f380c6c86b708c0c2bd3ad.gif)

### 1.3. [Pretty TypeScript Errors - Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=yoavbls.pretty-ts-errors)

让 TypeScript 报错变得更易读，可以直接跳转去 ts 的条目便于理解报错。
![IMG-B938B0F373C7753BD8D87DDBC89341B3](https://pictures.kazoottt.top/2025/10/20251020-b938b0f373c7753bd8d87ddbc89341b3.png)

### 1.4. [JSON to TS - Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=MariusAlchimavicius.json-to-ts)

快速把 json 转化为 ts 的类型

![](https://pictures.kazoottt.top/2025/10/20251020-53a8eb8fb52698d7a25c9a5d0437720b.gif)

### 1.5. [Error Lens - Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=usernamehw.errorlens)

直接在行内显示报错、告警信息

![IMG-509CA7645B9A6ADCA902128F8A22C777](https://pictures.kazoottt.top/2025/10/20251020-509ca7645b9a6adca902128f8a22c777.png)

### 1.6. [Better Comments - Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=aaron-bond.better-comments)

针对不同的注释类型展示不同的样式
![IMG-F5711D684B9A167E973583F479F4E5CF](https://pictures.kazoottt.top/2025/10/20251020-f5711d684b9a167e973583f479f4e5cf.png)

### 1.7. [Inline Parameters for VSCode](https://marketplace.visualstudio.com/items?itemName=liamhammett.inline-parameters)

用来在函数调用处显示参数名称的内联提示。

![](https://pictures.kazoottt.top/2025/10/20251020-79678d80033b96fb92a3b6b9c4ee7ff1.gif)

## 4. 非 vscode 无法使用 vscode 市场如何下载

vscode 关闭了离线下载的功能，且不允许非 vscode 使用它的源，这些非 vscode 都是使用的镜像源来下载插件的，所以可能存在一些插件无法下载的情况。
可以使用 [扣子](https://www.coze.cn/store/agent/7491642343327252489?bot_id=true) 的这个 agent，输入标识符 Unique Identifier 来下载离线文件。
