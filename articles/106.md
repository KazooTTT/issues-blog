`qkpr back` 命令用于从 merge 分支快速切换回源分支,提升 Git 工作流效率。

## 场景 1:单一匹配(最常见)

当只有一个匹配的源分支时,一键切换:

```bash
# 你在 merge 分支上解决了冲突
$ git branch
* merge/feat-M-12345-auth-to-main
  main
  feat/M-12345-auth

# 一行命令切回去
$ qkpr back

🔙  Back to Source Branch
  Merge branch: merge/feat-M-12345-auth-to-main
  Detected source: feat/M-12345-auth
  Detected target: main

🔄  Switching to source branch: feat/M-12345-auth
✅  Switched back to: feat/M-12345-auth
   (from merge branch: merge/feat-M-12345-auth-to-main)
```

## 场景 2:多个分支匹配

当存在多个可能的源分支时,提供选择菜单:

```bash
# 同时存在 feat/my-feature 和 feat-my-feature
$ qkpr back

🔙  Back to Source Branch
  Merge branch: merge/feat-my-feature-to-main

⚠️  Found 2 possible branch combinations:

? Which source branch do you want to switch to?
❯ feat/my-feature → main
  feat-my-feature → main
  ────────────────
  Cancel
```

## 场景 3:主菜单入口

在主菜单中作为第 5 个选项:

```bash
$ qkpr

╔══════════════════════════════════════════════════════════════╗
║                     🚀  Quick PR Tool                        ║
║           Your All-in-One Git Workflow Assistant             ║
║                      Author: KazooTTT                        ║
╚══════════════════════════════════════════════════════════════╝
            Version: 1.0.17

? What would you like to do?
  1. 🔧  Create Pull Request
  2. 🤖  Generate Commit Message
  3. 🌿  Generate Branch Name
  4. 🗑️  Delete Merge Branches
❯ 5. 🔙  Back to Source Branch    ← 新增的选项
  6. 📌  Manage Pinned Branches
  7. ⚙️   Settings
  ❌  Exit
```

## 场景 4:解析失败时(手动选择)

当 merge 分支名称不符合预期格式时,提供手动选择:

```bash
$ qkpr back

🔙  Back to Source Branch
  Merge branch: merge/invalid-name

❌  Could not parse merge branch name: merge/invalid-name
Expected format: merge/<source>-to-<target>

? Select source branch (type to search):
❯ feat/login-page
  fix/bug-456
  chore/update-deps
  ...
```

## 场景 5:本地没有源分支

当源分支不在本地时,提供从远程检出或其他选项:

```bash
$ qkpr back

🔙  Back to Source Branch
  Merge branch: merge/feat-new-api-to-develop
  Detected source: feat/new-api
  Detected target: develop

⚠️  Source branch 'feat/new-api' is not available locally.

? What would you like to do?
❯ Checkout from remote (origin/feat/new-api)
  Select a different branch
  Cancel
```

## 实现要点

- 自动解析 merge 分支名称,提取源分支和目标分支
- 支持多种分支命名格式的识别
- 提供交互式选择菜单处理歧义情况
- 优雅处理边界情况(解析失败、分支不存在等)
